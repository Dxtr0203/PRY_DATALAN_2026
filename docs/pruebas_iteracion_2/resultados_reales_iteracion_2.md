## Orden y diferencias confirmados antes de ejecutar

1. **Permanente:** Comercial registra y remite; Planta Técnica evalúa y deriva a Sistemas; Sistemas evalúa; Comercial toma la decisión final; Sistemas asigna responsables de Soporte; el Soporte asignado deriva a Planta Técnica; el técnico propone la inspección; Soporte confirma horario/equipo; el técnico registra la inspección; se programa y confirma la instalación; el técnico la registra; finalmente envía la conclusión y Soporte la revisa.
2. **Eventual:** comparte las etapas iniciales; después de inspección e instalación, se programa y aprueba el retiro eventual, el técnico registra el retiro y recién entonces queda habilitada la conclusión final. La secuencia que muestra el modal es inspección → instalación → retiro → conclusión.
3. La confirmación de equipos requiere una propuesta existente. La aplicación ofrece generar equipos desde Soporte mediante la API `api/propuesta-equipo-genetica/`; las pruebas de aprobación incluidas aquí usan propuestas ficticias preinsertadas en sus fixtures. Una prueba separada ejecuta la selección de equipo, pero no mide rendimiento ni acredita un recorrido visual de la API.
4. **Diferencia de regla:** Planta Técnica deriva la solicitud a Sistemas incluso si la evaluación no es factible. Comercial requiere que ambas áreas hayan registrado evaluación, pero el código permite la decisión comercial final aunque una de las áreas haya rechazado. La prueba `test_commercial_final_approval_overrides_an_area_rejection` verifica que solicitudes con rechazo de área pueden seguir siendo candidatas una vez marcadas con aprobación comercial; no ejecuta el POST de decisión comercial para esa combinación. Por tanto, “ambas evaluaciones registradas” no significa “ambas aprobadas”.
5. El código limita el retiro a solicitudes eventuales y exige completar el retiro antes de la conclusión eventual. También valida las fechas del retiro desde la fecha **HASTA** en adelante. Estas reglas se revisaron antes de las pruebas; no se simuló el transcurso del período real ni se cambió el reloj.
